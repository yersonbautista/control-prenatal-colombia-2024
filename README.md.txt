# Control prenatal en Colombia, 2024

## Descripción
Análisis exploratorio de datos sobre las consultas prenatales de los nacidos vivos en Colombia durante 2024, utilizando información de las Estadísticas Vitales del DANE.

## Autor
Leander Bautista

## Institución
Universidad Pedagógica y Tecnológica de Colombia (UPTC)

## Asignatura
Ciencia de Datos y Aprendizaje Automático para la Toma de Decisiones

## Contenido
- `informe.Rmd`: archivo fuente del análisis.
- `informe.html`: informe final en formato HTML.

## Datos
Fuente: Departamento Administrativo Nacional de Estadística (DANE), Estadísticas Vitales – Nacimientos 2024.

Los microdatos originales no se incluyen en este repositorio. Para consultar la fuente, visita el portal oficial del DANE.

## Reproducción
El análisis fue desarrollado en R utilizando R Markdown. Para reproducirlo se requiere disponer de los archivos de datos y documentación correspondientes y actualizar las rutas de acceso en el archivo fuente.
